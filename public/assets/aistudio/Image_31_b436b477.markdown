## Brand & Style

This design system establishes a high-performance, dark-first computational environment tailored for an advanced Persian-language AI ecosystem. It bridges the razor-sharp minimalism of platforms like Raycast, Vercel, and OpenAI with the atmospheric luminescence of subtle glassmorphism and soft neumorphic depth.

### Brand Personality & Philosophy
- **Computational Precision:** Clean lines, hyper-consistent spacing, and sub-pixel details that convey immediate latency-free responsiveness.
- **Atmospheric Sophistication:** Deep midnight charcoals paired with focused ultraviolet and neon photon accents, avoiding garish neon overload in favor of clinical, purposeful luminance.
- **Bilingual & RTL-Native Fluency:** Built from the foundational layer for Right-to-Left (RTL) reading mechanics, maintaining seamless parity between Persian body typography, Persian numerals, and Latin code/terminal strings.

### Visual Aesthetic & Hybrid Movement
The system balances two primary visual movements:
1. **Hypermodern Technical Minimalism:** Dense layouts, razor-thin translucent borders (`rgba(255, 255, 255, 0.08)`), structural grid discipline, and strict visual hierarchy.
2. **Luminous Glass & Neumorphic Nuance:** Surfaces utilize soft inner highlights (`inset 0 1px 0 rgba(255, 255, 255, 0.08)`), subtle deep backdrop blurs (12px to 24px), and diffuse colored photon glows behind primary interaction points.

## Colors

The color palette is engineered specifically for OLED/dark surfaces to eliminate eye fatigue during intensive prompt engineering, data modeling, and conversational workflows.

### Palette Architecture

- **Base Canvas (`#0B0F17`):** The deepest void tone used for the application background and outer frames.
- **Surface Elevation 1 (`#111827`):** Elevated structural background for panels, sidebars, and inactive modules.
- **Surface Elevation 2 (`#1F2937`):** Interactive card layers, dropdown menus, and popovers.
- **Primary Energy (`#6366F1` - Electric Indigo):** The focal signature token. Used for active generation indicators, focal CTAs, and primary state selections.
- **Secondary Aura (`#8B5CF6` - Cyberpunk Violet):** Used for AI synthesis states, dynamic model switching, and gradient overlays with Primary Indigo.
- **Tertiary Accent (`#3B82F6` - Neon Photon Blue):** Expressive highlight for code execution, live streaming tokens, and link affordances.

### Semantic & Feedback System
- **Operational / Connected (`#10B981`):** Active model nodes, API online status, successful tensor runs.
- **Warning / Calibration (`#F59E0B`):** Rate-limit throttling, context-window saturation warnings, pending authorizations.
- **Critical / Interruption (`#EF4444`):** Inference failure, malformed payload, token exhaustion.

### Text & Contrast Rules
- **Text Primary (`#F9FAFB`):** 98% opacity for body copy, titles, and high-priority figures.
- **Text Secondary (`#9CA3AF`):** Muted metadata, model parameter labels, secondary helper text.
- **Text Tertiary (`#6B7280`):** Inactive placeholders, disabled states, shortcut hints.
- **Translucent Borders:** Never solid. Use `rgba(255, 255, 255, 0.07)` for inactive boundaries and `rgba(99, 102, 241, 0.4)` for active focus rings.

## Typography

The typographic hierarchy accommodates right-to-left Persian script structures with seamless fallback into technical Latin scripts.

### Font Family Strategy
- **Persian Text Execution:** In production, standard system implementations map directly to `Vazirmatn` or `Dana`, utilizing OpenType features (`ss01`, `ss02`) to ensure full Persian numeral rendering (`۱۲۳۴۵۶۷۸۹۰`) across all body copy, timestamps, and analytics counters.
- **Latin Display & Code:** When rendering Latin brand headers, model names (e.g., `GPT-4o`, `Claude 3.5 Sonnet`, `Llama 3`), and technical endpoints, the pairing relies on **Outfit** for structural geometry, **Geist** for crisp data tables, and **JetBrains Mono** for prompt parameters, token counts, and Python/JSON inputs.

### RTL Vertical Rhythm & Metrics
Persian typography requires an expanded line-height relative to Latin glyphs to accommodate ascenders and descenders without clipping dots and diacritics. All Persian body copy tokens enforce minimum line-height multipliers of `1.6x` to `1.75x`. Numerical parameters, latency monitors, and token metrics enforce `JetBrains Mono` with directional isolation (`dir="ltr"` and `unicode-bidi: isolate`) to prevent alignment flipping inside RTL containers.

## Layout & Spacing

The layout is grounded in a flexible, 12-column responsive grid built with a strict 4px/8px incremental rhythm.

### Grid Model & Breakpoints
- **Desktop (>= 1280px):** 12-column fluid grid, `2rem` (32px) outer margins, `1.25rem` (20px) column gutters. Dedicated fixed right-side utility drawer (280px) and left-side contextual inspection panel (340px).
- **Tablet (768px - 1279px):** 8-column layout, `1.5rem` margins, `1rem` gutters. Sidebars fold into an elevated command bar overlay.
- **Mobile (< 768px):** 4-column layout, `1rem` margins, `0.75rem` gutters. Panels become bottom sheets with spring physics.

### Spacing Usage Rules
- `space-xs` (4px): Micro gaps between status indicator dots and text, chip internal iconography.
- `space-sm` (8px): Gap between form labels and inputs, list-item internal padding.
- `space-md` (16px): Standard padding inside cards, chat bubbles, and toolbar clusters.
- `space-lg` (24px): Padding within major sections, modal interior offsets.
- `space-xl` (40px): Section dividers and landing hero vertical buffers.

## Elevation & Depth

Visual hierarchy uses luminous dark-surface depth rather than heavy physical dropshadows, achieving a lightweight, high-tech interface.

### Depth Layers

- **Level 0 (Canvas Base):** Solid `#0B0F17`. Ground plane.
- **Level 1 (Card & Modular Paneling):** Semi-transparent `#111827` at 80% opacity, layered with `backdrop-filter: blur(16px)` and a subtle single-pixel border: `border: 1px solid rgba(255, 255, 255, 0.06)`. Top edge features an inner stroke `inset 0 1px 0 0 rgba(255, 255, 255, 0.08)` providing a crisp edge highlight.
- **Level 2 (Floating Popovers, Menus & Toolbars):** `#1F2937` at 90% opacity, blur of 24px, accompanied by an ambient dark shadow: `box-shadow: 0 12px 32px -4px rgba(0, 0, 0, 0.65), 0 0 0 1px rgba(255, 255, 255, 0.1)`.
- **Level 3 (Modal Dialogs & Command Palettes):** Pure glassmorphic sandwich: background `rgba(17, 24, 39, 0.85)`, backdrop blur of 32px, bordered by `rgba(99, 102, 241, 0.25)` and a subtle localized outer glow: `box-shadow: 0 24px 64px -12px rgba(0, 0, 0, 0.85), 0 0 24px -2px rgba(99, 102, 241, 0.15)`.

### Soft Neumorphic Inset Shading
For prompt input bars and active terminal consoles, shallow concave depths are achieved using dual inner shadows:
`box-shadow: inset 0 2px 4px rgba(0, 0, 0, 0.5), inset 0 -1px 1px rgba(255, 255, 255, 0.03)`.

## Shapes

The shape system employs deliberate geometric rounding (`roundedness: 2` base) to balance technical precision with modern, touch-friendly softness.

### Shape Hierarchy
- **Base Elements (`0.5rem` / 8px):** Badges, tag chips, input elements, buttons, and action menu triggers.
- **Cards & Paneling (`1rem` / 16px):** Chat message groupings, model config containers, metric preview tiles.
- **Modals & Flyouts (`1.5rem` / 24px):** Command palettes, prompt generation workspaces, setting hubs.
- **Pill Exceptions (`9999px`):** Status indicator pills, token counter badges, and floating bottom omni-bars.

## Components

### Buttons
- **Primary Cyber:** Background gradient from `#6366F1` to `#8B5CF6`. Clean white text (`#F9FAFB`), subtle top inset highlight (`inset 0 1px 0 rgba(255, 255, 255, 0.2)`), soft neon glow on hover (`0 0 16px rgba(99, 102, 241, 0.4)`). Active state scales slightly down to `0.98`.
- **Secondary Ghost:** Transparent background with `#1F2937` hover fill, bordered with `rgba(255, 255, 255, 0.08)`. Text in `#F9FAFB`.
- **Destructive:** Background `rgba(239, 68, 68, 0.1)`, border `rgba(239, 68, 68, 0.25)`, text `#EF4444`. Hover intensifies background to `rgba(239, 68, 68, 0.2)`.

### Input Fields & Prompt Consoles
- **Interactive States:** Background `#0E1420` with concave inner shadow. Static border `1px solid rgba(255, 255, 255, 0.08)`. 
- **Focus Ring:** Inset and outer transition smoothly to `#6366F1` border and a diffused blue-violet photon ring: `box-shadow: 0 0 0 2px rgba(99, 102, 241, 0.25)`.
- **RTL Typography Rules:** Labels and placeholders aligned to the right. Affordances such as file attachments, microphone triggers, and token counter chips are pinned to the left edge of the input.

### Cards & Container Panels
- Glass-backed canvas containers featuring `#111827` at 75% opacity, `backdrop-filter: blur(16px)`, rounded corners (`16px`), and micro-borders (`1px solid rgba(255, 255, 255, 0.06)`).
- Hover states on interactive cards activate a gradient sweep border using CSS `mask-composite` or subtle border highlight transition to `rgba(99, 102, 241, 0.3)`.

### Chips & Filter Tags
- Compact rounded items (`8px`), background `rgba(255, 255, 255, 0.03)`, border `1px solid rgba(255, 255, 255, 0.06)`. 
- Active state transitions background to `rgba(99, 102, 241, 0.15)` with text `#6366F1` and border `rgba(99, 102, 241, 0.4)`.

### Checkboxes & Toggle Switches
- **Switches:** Track uses `#1F2937` (44px width, 24px height). Active state transforms to linear gradient `#6366F1` -> `#8B5CF6`. The thumb is a pure white circular disc (`18px`) that slides from right to left in RTL mode.
- **Checkboxes:** 18x18px squares with 4px border radius. Filled with `#6366F1` upon selection, presenting a white micro checkmark icon.

### Domain-Specific AI Components
- **Streaming Response Bubble:** Zero background container with subtle right-side gradient line highlight indicating AI response boundaries. Persian text streams with an animated glowing caret (`2px` width, `#6366F1`, pulsating every 800ms).
- **Latency / Token Indicator:** Pill element (`JetBrains Mono`, Latin numbers) paired with a live dot: `8px` pulsating green disc (`#10B981`) wrapped in a blurred radial shadow (`0 0 8px #10B981`).
- **Prompt Parameter Sliders (Temperature / Top-P):** Thin track (`4px`, `#1F2937`), dynamic fill gradient `#6366F1`, and a draggable luminous thumb with `box-shadow: 0 0 10px rgba(99, 102, 241, 0.8)`. Numerical indicators positioned left in Latin monospace.
